# 🖐️ 指尖魔法 - 3D粒子交互特效

一个基于 **Three.js** 和 **MediaPipe** 的神奇手势识别交互项目！通过摄像头识别手势，触发炫酷的3D粒子特效。

## ✨ 功能特性

| 手势 | 特效 |
|------|------|
| 👆 1根手指 | 粒子数字"1" |
| ✌️ 2根手指 | 粒子数字"2" |
| 3️⃣ 3根手指 | 粒子数字"3" |
| 🖐️ 5指张开 | 终极告白："U"粒子文字 + 3D气球 + 鲜花 |
| ✊ 握拳 | 立即重置，清空屏幕 |

## 📱 移动端完美支持

已针对移动设备进行全面优化：

| 特性 | 说明 |
|------|------|
| **响应式布局** | 自适应各种屏幕尺寸 |
| **性能优化** | 移动端自动降低粒子数量，保证流畅 |
| **触摸按钮** | 移动端显示快捷按钮，方便使用 |
| **摄像头适配** | 移动端自动调整摄像头分辨率 |
| **全屏支持** | 支持移动端全屏模式 |
| **WebApp模式** | 支持添加到主屏使用 |

## 📝 技术栈

- **Three.js r128** - 3D渲染引擎
- **MediaPipe Hands** - 手势识别
- **纯HTML/CSS/JavaScript** - 无需复杂框架

## 🎯 核心实现

### 手势识别
使用 MediaPipe Hands 检测手部关键点，通过计算指节和指尖位置来判断伸出的手指数量。

### 3D粒子系统
- 彩色发光球体粒子
- 粒子按特定路径组成数字和字母
- 动态脉冲和旋转动画
- 自动生命周期管理
- 移动端性能优化（自适应粒子数量）

### 3D气球和鲜花
- 气球：球体变形 + 绳子
- 鲜花：6片花瓣 + 中心
- 向上漂浮 + 摇摆动画
- 移动端自动缩放

## 🎨 设计理念

- **极简风格**：纯黑背景，专注于粒子效果
- **流畅动画**：60fps 丝滑体验
- **即时反馈**：手势识别后立即显示特效
- **纯净交互**：没有多余的UI元素，只有魔法

## 📌 注意事项

1. **光线要求**：确保光线充足，让摄像头能清晰识别手势
2. **摄像头权限**：必须允许浏览器访问摄像头
3. **浏览器支持**：建议使用 Chrome、Edge 或 Firefox
4. **HTTPS**：摄像头需要 HTTPS 或 localhost 环境
5. **移动端**：推荐使用现代浏览器，建议在光线充足环境使用
